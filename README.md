# El Ahorcado

Juego del ahorcado con palabras y comidas colombianas: adivina la palabra
letra por letra antes de que se complete el dibujo. Cada palabra trae su
significado como pista. Tiene 80 palabras en 4 niveles (gana 3 para pasar al
siguiente) y sonidos colombianos (acordeón, guacharaca, maracas y tambora)
hechos con la Web Audio API, con botón para silenciarlos.

Hecho con Next.js, TypeScript y Tailwind CSS.

## Cómo correrlo en tu computadora

```bash
npm install
npm run dev
```

Luego abre http://localhost:3000
